# БСПБ FX Control

Исследование для Банка «Санкт-Петербург». FX Control помогает менеджеру ВЭД подтвердить валютную оговорку, оценить остаточный риск бюджета и передать запрос на котировку в казначейство. Изучены три компонента: исторические сценарии HedgeLab, правила поиска оговорок FX Scanner и экономика запуска через действующих менеджеров.

Срез исследования — **14 ноября 2026 года**. Рекомендация — **Conditional Go на исследовательский пилот до 0,65 млн ₽**. В базовом сценарии NPV за 36 месяцев составляет **−0,73 млн ₽** при простой окупаемости 31,9 месяца. Результаты пилота, цена исполнения и фактический спрос на Premium ещё не наблюдались.

## Воспроизведение

Нужен Python 3.12. Из корня репозитория установите зависимости и пакет локально. Для первоначальной установки нужен доступ к PyPI или к зеркалу с этими пакетами. Сами расчёты читают закреплённые данные и работают без сети. На Windows выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e . --no-deps
.\.venv\Scripts\python.exe scripts/reproduce.py
.\.venv\Scripts\python.exe -m pytest -q
```

На Linux и macOS вместо `.\.venv\Scripts\python.exe` используйте `.venv/bin/python`. В Windows с ограничениями на системную временную папку укажите тестам новую пустую папку внутри проекта, например `--basetemp output/pytest-local`.

| Эксперимент | Результаты запуска |
| --- | --- |
| HedgeLab: курсы, хеджирование, чувствительность, 696 проверенных ячеек кейса | `output/hedgelab/` |
| Инвестиционная модель: 8 конфигураций × 3 сценария, стрессы, проверка Excel, пилотный бюджет | `output/investment/` |
| FX Protection Gap: макроряды, 9 комбинаций, 3 графика | `output/macro/` |
| Scanner: русскоязычные диагностические примеры, при подключении CUAD также английский корпус и очередь разметки | `output/scanner/` |

Чтобы воспроизвести английский Scanner, скачайте **CUAD_v1.zip** из официальной записи The Atticus Project и передайте локальный путь. При самостоятельном запуске этот шаг также работает без сети. [The Atticus Project, Zenodo](https://zenodo.org/records/4595826)

```powershell
.\.venv\Scripts\python.exe scripts/run_scanner.py --cuad C:\data\CUAD_v1.zip
```

Драйверы модели лежат в `configs/`. Для изменения гипотез используйте `scripts/run_investment.py`. `scripts/audit_investment.py` сверяет опубликованный baseline Excel v3.1, поэтому ожидает его исходные параметры. Полный запуск проверяет SHA-256 всех закреплённых входов и записывает CSV и PNG в игнорируемую папку `output/`. Excel — проверяемый снимок с формулами, а основной способ пересчёта экспериментов — Python.
